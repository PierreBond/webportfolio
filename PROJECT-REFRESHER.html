1. Infinity Gym

Immersive Gym Website
Immersive gym website with 3D graphics, smooth scrolling, and AI integration.
Tech Stack
React 19 · Vite · TypeScript · Tailwind CSS 4 · Three.js · GSAP · Lenis · Express · Google Gemini AI
Architecture
  • React SPA frontend (Vite) + small Express backend for AI endpoints.
  • 3D scenes built with Three.js; scroll animations driven by GSAP + Lenis smooth scroll.
  • Google Gemini API integrated through the Express backend (API key stays server-side).
Key Implementation
  • Three.js scenes: custom 3D geometry + lighting rendered behind the content, performance kept in check with capped pixel ratio.
  • GSAP scroll timelines: ScrollTrigger pin + scrub animations; SplitType for per-character text reveals.
  • Lenis: hijacks native scroll for buttery 60fps scrolling, synced to GSAP ticker.
  • Infinite dragging slider: GSAP Draggable + modulo loop (Osmo technique).
  • AI feature: frontend POSTs to Express → calls Gemini → returns response (keeps key hidden).
How to explain it
"I built a fully animated gym site — 3D scenes with Three.js, scroll-driven GSAP timelines, Lenis smooth scrolling, and a Gemini AI chat feature behind an Express proxy. The trickiest part was syncing Lenis with GSAP's ticker so scroll animations stayed in sync."

2. Faceneed

Beauty E-Commerce Platform
Luxury beauty e-commerce platform for premium skincare and makeup products.
Tech Stack
React 19 · Vite · TypeScript · Tailwind CSS 4 · Framer Motion · Zustand · Recharts
Architecture
  • Frontend-only SPA — product data managed in-app; state via Zustand stores.
  • Pages: catalog, product detail, cart, wishlist, admin dashboard.
  • Admin dashboard uses Recharts for sales/order analytics.
Key Implementation
  • Zustand stores: cart + wishlist stores persist to localStorage automatically (middleware).
  • Dynamic theming: page-specific color palettes swapped via CSS custom properties on route change.
  • Glassmorphism UI: backdrop-filter blur layers + Framer Motion page transitions.
  • Real-time search/filter: catalog filters computed reactively from store state (no API calls).
How to explain it
"It's a luxury e-commerce SPA. State lives in Zustand stores that auto-persist cart and wishlist to localStorage. Each page has its own color palette applied through CSS variables, and Framer Motion handles the page transitions for that premium feel."

3. SportAnalyst

Sports Prediction Dashboard
Sports prediction dashboard with real-time data and ML explainability.
Tech Stack
Next.js 16 · TypeScript · Tailwind CSS · FastAPI (Python) · PostgreSQL · XGBoost · WebSockets · Jest
Architecture
  • Next.js frontend + FastAPI backend + PostgreSQL (Docker Compose: 3 containers).
  • XGBoost ML model (68% accuracy, 9 leagues) served by FastAPI.
  • Alembic for DB migrations; CI/CD pipeline; PDF report export.
Key Implementation
  • Prediction pipeline: batch job scores 500+ matches; XGBoost predicts outcomes with confidence scores.
  • Value bet detection: compares model probabilities against live bookmaker odds — flags edge cases.
  • SHAP explainability: waterfall charts show which features drove each prediction.
  • Real-time odds: WebSockets push live odds/line movements to the dashboard.
  • Testing: Jest + React Testing Library full suite on the frontend.
How to explain it
"Full-stack sports prediction platform. An XGBoost model trained on 9 leagues makes predictions, and I compare its probabilities against live bookmaker odds to find value bets. SHAP charts explain every prediction, WebSockets stream live odds, and the whole thing runs on Docker Compose with FastAPI and Next.js."

4. Silo

Barter Trading Mobile App
Mobile-first barter trading app — list items, find trades, chat with partners.
Tech Stack
React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · React Router v7 · Vitest · React Testing Library
Architecture
  • Mobile-first SPA (single-column layout, touch-friendly).
  • Client-side routing via React Router v7; state via local hooks + localStorage.
  • Full test suite with Vitest + React Testing Library.
Key Implementation
  • Core flows: feed → item detail → propose trade → counter-offers → chat.
  • Map discovery: items plotted geographically for local bartering.
  • Real-time chat: message threads per trade with optimistic UI updates.
  • Trade engine: propose / accept / counter-offer state machine per trade.
  • Testing: Vitest unit + integration tests covering trade logic and components.
How to explain it
"Mobile-first barter app — you list items, discover nearby trades on a map, propose trades with counter-offers, and chat with partners. The interesting part was the trade state machine (propose/accept/counter) and making it fully tested with Vitest."

5. Inventory Advisor

Offline Inventory Management PWA
Offline-first inventory management progressive web app.
Tech Stack
React 19 · Vite · Tailwind CSS 4 · PouchDB · React Router v7 · vite-plugin-pwa
Architecture
  • PWA with service worker — installable, works with zero connectivity.
  • PouchDB (IndexedDB wrapper) as the local database — no backend required.
  • React Router v7 for app navigation; manifest + service worker via vite-plugin-pwa.
Key Implementation
  • Offline-first design: all reads/writes go to PouchDB first; UI never blocks on network.
  • Service worker: caches the app shell so it loads instantly on repeat visits.
  • PouchDB sync (optional): can replicate to a CouchDB-compatible server when online.
  • CRUD: inventory items (add/edit/delete/quantity) persisted in IndexedDB.
How to explain it
"Offline-first inventory PWA. All data lives in PouchDB on the device — IndexedDB under the hood — so it works with no internet at all. The service worker caches the app shell, and it's installable to the home screen. Can optionally sync to a server when back online."

6. PlacePal

Apartment Search Platform
Full-stack apartment search platform with map-based discovery.
Tech Stack
React 19 · Express · Prisma ORM · PostgreSQL (Neon) · Leaflet/React-Leaflet · WebSockets · Zod · Multer · JWT auth · Docker
Architecture
  • React frontend + Express REST API + PostgreSQL (Neon) via Prisma ORM.
  • JWT + bcrypt authentication; Docker Compose for the database.
  • Deployed: frontend on Vercel, backend on Railway.
Key Implementation
  • Map discovery: React-Leaflet renders apartment listings as markers/clusters; click → detail panel.
  • Auth flow: JWT issued on login, attached as Bearer header; bcrypt hashes passwords.
  • Zod validation: request bodies validated at the API boundary before hitting Prisma.
  • Image upload: Multer handles multipart uploads (listings photos), stored server-side.
  • Real-time updates: WebSockets broadcast listing changes to all connected users.
  • Rate limiting + CORS: Express middleware protects the API.
How to explain it
"Full-stack apartment search — browse listings on an interactive Leaflet map, JWT auth, Zod-validated API, Multer image uploads, and WebSockets for live listing updates. Prisma on Postgres, Docker for the DB, deployed frontend on Vercel and backend on Railway."
